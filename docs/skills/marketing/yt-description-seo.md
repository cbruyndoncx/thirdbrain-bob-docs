# yt-description-seo

Optimize YouTube video descriptions, tags, timestamps, and hashtags for maximum search discoverability without keyword-stuffing. Descriptions are the single biggest metadata lever creators ignore -- most paste a link and forget about the 5,000-character field that YouTube indexes for search. A well-written description increases click-through from search results, activates video chapters, and drives traffic to CTAs.

- **Area:** Marketing
- **Category:** content
- **Level:** beginner
- **Input:** conversation
- **Output:** code
- **Setup:** none
- **Roles:** Content Manager

Write and optimize YouTube video descriptions, metadata, tags, timestamps, and hashtags for search discoverability.

## How you ask

- “Write a description”
- “Video description”
- “YouTube SEO”

## Inputs

- video_title — The published or planned video title
- topic — What the video covers in one sentence
- sections — 3-8 main sections or key points with approximate timestamps
- primary_cta — Primary call-to-action (subscribe, lead magnet, product link, next video)
- keywords — Target keywords if known (skill will research if not provided)
- links — Tools, resources, or URLs to include
- transcript — Video script or transcript .md file
- title — Video title (used in output header)
- output — Output .md path (default: scratch output, `output.scratch`, `promises_{slug}.md`)

## Outputs

- Full description, tags, hashtags, and SEO notes
- prefer a permanent directory)
- promise-checklist (markdown)
- {company.marketing}/video/metadata/{video-slug}_description_{YYYY-MM-DD}.md
