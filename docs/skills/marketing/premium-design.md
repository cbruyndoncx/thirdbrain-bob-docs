# premium-design

A catalog-driven skill for building premium, editorial, high-end interfaces. Distinct from the general `visual-designer` skill: this one is opinionated about typography, motion, and restraint.

- **Area:** Marketing
- **Category:** marketing funnel
- **Level:** beginner
- **Input:** conversation
- **Output:** document
- **Setup:** none
- **Roles:** 

Builds premium, editorial-grade web interfaces for high-end brands, luxury products, design-forward SaaS, and creative portfolios.

## How you ask

- “Compose a premium landing page from this brand-register DESIGN.md and the editorial catalog.”
- “Turn this portfolio brief into a kinetic luxe page without hardcoded colors.”
- “Validate this rendered premium page for token compliance, contrast, motion, and design slop.”

## Inputs

- design-system — Brand design system — colors, type, tokens.
- product-design-system — Product-level design system, when scoped to a product.
- client-design-system — Client design system, when scoped to a client.
- design-spec — Brand-register DESIGN.md containing colors, typography, spacing, motion, and color strategy.
- page-brief — Page type, content, required sections, project directory, and responsive expectations.
- rendered-page — Rendered HTML output to validate against the source DESIGN.md and quality gate.

## Outputs

- page-source (html-css-tsx)
- prefer a permanent directory)
- validation-report (markdown)
- {project-dir}/
