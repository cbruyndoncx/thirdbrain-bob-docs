# yt-studio-analytics

For content creators, marketing managers, and agency teams who need YouTube channel performance data for content strategy decisions.

|---|---|
| **Area** | Marketing |

| **Level** | expert |

Extract YouTube channel analytics — video performance data (views, CTR, avg view duration, subscribers), channel-level metrics, and competitive benchmarks.

## How you ask

- “Pull my YouTube analytics”
- “Video performance report”
- “YouTube channel metrics”

## Inputs

- channel — YouTube channel URL, handle (@name), or channel ID
- count — Number of recent videos to analyze
- metrics — Metrics to include
- channel — YouTube channel URL, handle, or channel ID
- channels — List of YouTube channel URLs or handles to compare
- count — Recent videos per channel to compare

## Outputs

- prefer a permanent directory)
- report (markdown)
- spreadsheet (xlsx)
