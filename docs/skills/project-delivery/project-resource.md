# project-resource

Create a resource plan that shows demand versus capacity, flags over-allocation, and recommends leveling or acquisition actions.

- **Area:** Project Delivery
- **Category:** project management
- **Level:** intermediate
- **Input:** conversation
- **Output:** document
- **Setup:** none
- **Roles:** Operations Manager

Analyzes project resource allocation, detects over-allocation, and recommends leveling moves.

## How you ask

- “Analyze resource allocation across our project”
- “Detect over-allocated team members and recommend leveling”
- “Generate a resource histogram for the next quarter”
- “Optimize resource assignments across our project phases”

## Inputs

- schedule — Complete schedule with activities, durations, dependencies, assignments, and float (from `project-schedule`), converted to the leveling script's JSON input in Step 2.
- request — The resource question to answer — full plan, capacity check, or leveling pass — and the period unit to use.
- profile — Company or client profile — delivery standards and project context the leveling recommendations must respect.
- schedule — Partial schedule, where one exists — read for whatever activities, assignments, or float it does cover; everything it does not cover is filled with a stated default assumption.
- request — The resource question to answer, plus whatever team roster, capacity, or assignment detail the caller can supply directly since the schedule is incomplete.
- schedule — Schedule, where one exists, read to build the assignment matrix by hand since the script cannot be run.
- request — The resource question to answer, given that the analysis will be produced by reasoning rather than the script.

## Outputs

- Assignment matrix and over-allocation analysis, with every assumed capacity, float, or assignment value labeled.
- Assignment matrix, over-allocation analysis, and leveling recommendations, with the histogram embedded.
- Manually assembled assignment matrix, over-allocation analysis, and leveling recommendations, with the script error reported and the histogram explicitly noted as unavailable.
- Stacked-bar demand-versus-capacity histogram generated by `resource_leveler.py`.
- Stacked-bar demand-versus-capacity histogram generated from the assumption-filled input.
- {project-folder}/resource_histogram.svg
- {project-folder}/resource_plan.md
