# growth-embedded

Use this skill when growth should be designed into the product deliberately, not bolted on after launch.

| | |
|---|---|
| **Area** | Strategy |
| **Category** | product management |
| **Level** | beginner |
| **Input** | conversation |
| **Output** | document |
| **Setup** | [none] |
| **Roles** | [Head of Marketing, Product Manager] |

Designs activation loops, viral growth mechanics, product-led growth features, user acquisition loops, onboarding sequences, and referral tracking inside the product.

## How you ask

- “Design a viral growth loop for our product”
- “Build activation mechanics for our onboarding flow”
- “Create a referral tracking system inside our product”
- “Design product-led growth features for user acquisition”

## Inputs

- request — What to produce
- scope — `company`, or a client-id under {company.clients}/ — a string with one reserved value, not a closed set

## Outputs

- growth-embedded (markdown)
- {scope.knowledge-base.product}/growth-embedded-{YYYY-MM-DD}.md
