# pdf-to-pptx

Extracts text, tables, and images from PDF pages and creates native editable PowerPoint slides — not screenshots, but real text boxes, real tables, and positioned images. Automatically detects and OCRs image-only pages (like NotebookLM slide exports where text is baked into PNGs).
