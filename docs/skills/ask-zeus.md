# ask-zeus

Your strategic adviser for achieving stated objectives through clarity, leverage, and integrity.

|---|---|
| **Area** | Strategy |

1:1 strategic coaching using first-principles thinking and mental models against the user's personal knowledge base.

## How you ask

- “ask zeus”
- “coach me”
- “I need advice”
- “help me decide”
- “Zeus.”

## Inputs

- request — The bounded choice and its near-term deadline — what is being decided and by when.
- scope — `company`, or a client-id under {company.clients}/ — a string with one reserved value, not a closed set
- request — The complex or identity-level trade-off to analyze, including known variables, constraints, and what has already been ruled out.
- request — The goal, principle, or time period to check recent actions against.
- request — The problem or situation the user is still working out, without a decision already framed.

## Outputs

- Accountability review — stated goals compared to recent actions, drift or gaps flagged, and course corrections suggested.
- D-S-F-C record — the deconstructed decision, knowledge-base synthesis, mental model applied, and the recommendation with named trade-offs.
- Reflective question set that surfaces the real problem beneath the one originally stated.
- Session record for the quick-decision pass — clarifying questions asked, the quick filter applied, and the call made.
- {scope.processes}/ask-zeus-{YYYY-MM-DD}.md
