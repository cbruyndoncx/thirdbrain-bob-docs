# visual-designer

Applies formal design principles and practical tool guidance to produce professional-quality visual materials — from pitch decks to social posts. Bridges the gap between design theory and tool execution so non-designers get results that look intentional.

Applies visual design principles and practical tool guidance to audit, improve, and create professional marketing materials.

## How you ask

- “Can you audit this pitch deck design and tell me what to fix?”
- “What fonts should I use for my company presentation on Gamma?”
- “My slide looks too busy — how do I fix the layout?”
- “Create a design system for my client's brand using navy and gold”
- “How do I set up a dark theme deck in Canva?”
- “Is my color contrast accessible?”
- “Help me design a social media post for this campaign”

## Inputs

- design-system — Brand design system — colors, type, tokens.
- product-design-system — Product-level design system, when scoped to a product.
- client-design-system — Client design system, when scoped to a client.
- design_asset — Screenshot, file, or verbal description of the design to audit
- tool — Tool used to critique an existing design across 6 dimensions with graded scores and actionable fixes (canva | figma | gamma | google-slides | powerpoint)
- material_type — Slide deck, brochure, social post, infographic, etc.
- tool — Tool used to structure a material from scratch or improve an existing layout with grid and spacing rules (canva | figma | gamma | google-slides | powerpoint)
- brand_context — Colors, fonts, logo, aesthetic goals
- aesthetic_goal — Professional, bold, warm, technical, cinematic, etc.
- material_type — loaded from your vault context

## Outputs

- 2-3 ranked options with rationale and contrast checks
- Color palette, typography scale, spacing scale, component patterns, gaps
- Named layout pattern, spacing rules, hierarchy, tool steps
- Per-dimension grades, top 3 fixes, secondary improvements
- prefer a permanent directory)
