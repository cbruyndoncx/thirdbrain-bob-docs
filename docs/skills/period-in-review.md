# period-in-review

Produces a chronological "status / year-in-review" reel from a window of AI-assisted work: it measures what was done (from Claude Code session transcripts) and montages what was produced (real vault artifacts), rendered as an on-brand portrait video. Re-runnable on any period and scope, so the same skill makes a monthly all-work recap, a quarterly board reel, or a per-client "here's everything we shipped for you" video.

Turns a period of AI-assisted work into a shareable status reel — measures the real work done (sessions, prompts, actions, tokens) from Claude Code session logs,…

## How you ask

- “Period in review”
- “Year in review”
- “Month in review”

## Inputs

- period — start (inclusive) / --end (exclusive) ISO dates.
- scope — all | client:{client-id} | project:{fragment}. Default all.
- period — start/--end ISO range.

- prefer a permanent directory)
- props (json)
- reel (mp4)
- stats (json)
