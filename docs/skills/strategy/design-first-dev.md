# design-first-dev

Use this skill when the team needs to decide how much craft to invest and what must be designed before build starts.

- **Area:** Strategy
- **Category:** product management
- **Level:** beginner
- **Input:** conversation
- **Output:** document
- **Setup:** none
- **Roles:** Product Manager

Creates feature specs, defines all-state UX requirements, prototypes interactions, and sets craft-level standards for design-led development.

## How you ask

- “Create a feature spec with all-state UX requirements”
- “Define the design system standards for this feature”
- “Set craft-level quality standards for our product”
- “Prototype the interaction design for our settings page”

## Inputs

- request — What to produce
- scope — `company`, or a client-id under {company.clients}/ — a string with one reserved value, not a closed set

## Outputs

- design-first-dev (markdown)
- {scope.knowledge-base.product}/design-first-dev-{YYYY-MM-DD}.md
