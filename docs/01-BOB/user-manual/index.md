# BOB User Manual

**BOB — the Business Operating Brain.** This is the full user manual: a classical software description covering the system, its modules, its data model, and its operation. Read chapters 1–5 in order once; everything after that is designed for direct access.

> **A promise about this guide**
> You do not need to be technical to use BOB. You never edit code: you describe what you need in plain English, review what comes back, and approve it. Installing it yourself is the technical part (Node, npm, WSL2 on Windows and a terminal); assisted setup does that for you.
