- **Frequency:** Per delivery process overhaul

## Inputs

- 🏢 Client name and project types
- 👥 Team size and roles
- ⏱️ Average project duration and pain points

## What BOB does

1. business-baseline → map delivery workflows and waste
2. Review delivery map — confirm bottlenecks
3. project-schedule → create optimized templates with CPM
4. project-resource → analyze resource allocation and leveling
5. kpi-dashboard-design → design delivery performance dashboard
6. time-tracking-reporter → set up utilization tracking

## Outputs

- 📅 Optimized delivery schedule templates
- 👥 Resource allocation plan
- 📊 Delivery performance dashboard
- ⏱️ Utilization tracking setup

## Benefits

- 4× faster
- Resource conflicts visible before they hit
- KPIs tracked automatically
