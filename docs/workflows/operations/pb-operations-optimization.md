# Nothing is documented.

*Documented processes with visual maps and operating dashboard*

> Nothing is documented.
> Every process lives in someone's head.

**Outcome:** Processes documented, visually mapped, dashboard built, SOPs extracted.

- **Area:** Operations
- **Time savings:** ~10 hrs manual → ~2.5 hrs automated (4× faster)
- **Try it:** "Client experiencing operational chaos or scaling pain"
- **Compounding:** SOPs and dashboards become the operating system for the business
- **Frequency:** Per operational overhaul
- **Published:** 2026-04-01

## Inputs

- 🏢 Client name and industry
- ⚠️ Key operational pain points
- 🛠️ Current tools and systems

## What BOB does

1. business-baseline → map operations and bottlenecks
2. Review business map — flag inaccuracies and priorities
3. operating-dashboard → build visual operating dashboard
4. d2-diagram → create process flow diagrams
5. technical-writing → document SOPs for optimized processes
6. playbook-runner → create process playbooks

## Outputs

- 🗺️ Operations business map
- 📊 Operating dashboard canvas
- 📐 Process flow diagrams
- 📋 SOPs and process playbooks

## Benefits

- 4× faster
- Visual maps reveal bottlenecks
- SOPs make delegation possible
