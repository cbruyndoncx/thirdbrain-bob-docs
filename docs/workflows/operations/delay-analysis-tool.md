# Delay Analysis Tool

*Time Impact Analysis (TIA)*

> The project is late.
> Proving whose fault it is takes weeks.

- **Area:** Operations
- **Level:** expert
- **Roles:** Operations Manager
- **Time savings:** ~1-2 days manual CPM analysis → ~20 min automated
- **Try it:** "Analyze the delay impact of 3 weeks late site access on our critical path"
- **Compounding:** Each TIA strengthens the project delay record — cumulative evidence for arbitration
- **Frequency:** Per delay event · monthly schedule update

## Inputs

- 📊 approved-baseline.xlsx
- ⏱️ delay-event-description.md

## What BOB does

1. Establish baseline and critical path
2. Define delay event
3. Construct and insert fragnet
4. Recalculate CPM
5. Verify net delay figure
6. Compile TIA report

## Outputs

- 📋 tia_report.md
- ⚖️ concurrent_delay_assessment.md
