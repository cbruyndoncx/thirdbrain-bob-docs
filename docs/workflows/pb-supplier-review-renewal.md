> Supplier contract renewing.
> But you have no data on whether they're actually good.

**Outcome:** Performance assessed, renewal decision made, next steps actioned.

| | |
|---|---|
| **Area** | Operations |
| **Time savings** | ~3 hrs manual → ~1 hr automated (3× faster) |
| **Try it** | "Quarterly review or contract expiring within 90 days" |
| **Compounding** | Scorecard history reveals trends — poor performers flagged before renewal |
| **Frequency** | Quarterly per supplier |
| **Published** | 2026-04-01 |

## Inputs

- 🏢 Supplier ID(s) to review
- 📅 Review period (e.g. Q1 2026)
- ⚠️ Performance incidents to note

## What BOB does

1. supplier-feedback → 5-dimension performance scorecard
2. Review scores, compare to prior periods, flag concerns
3. strategic-sourcing → contract lifecycle check, Kraljic reassessment
4. Decide: renew, renegotiate, recompete, or terminate
5. strategic-sourcing → prepare negotiation brief or new RFx

## Outputs

- 📊 Performance scorecard with trends
- 📋 Contract lifecycle assessment
- 🔄 Renewal recommendation
- 📄 Negotiation brief or RFx (if needed)

## Benefits

- 3× faster
- Scorecard history shows trends
- Renewal decisions backed by evidence
