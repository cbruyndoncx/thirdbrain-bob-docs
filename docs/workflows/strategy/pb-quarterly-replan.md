# Quarterly Replan

*Strategic Reset*

> New quarter.
> Same plan you stopped believing in weeks ago.

- **Area:** Strategy
- **Time savings:** ~2 days strategic offsite → ~2 hrs automated
- **Try it:** "Quarterly replan" or start of quarter
- **Compounding:** Each quarter builds on prior diagnosis — strategic drift detected faster
- **Frequency:** Quarterly

## Inputs

- 📊 last-quarter-results.md
- 🎯 strategic-constraints.md

## What BOB does

1. business-baseline → current state map
2. growth-scaling-playbook → diagnose stage
3. Confirm growth stage
4. strategy-frameworks → strategic choices
5. okr-frameworks → draft OKRs
6. Adjust OKRs
7. prioritization-craft → RICE initiatives
8. project-schedule → quarter timeline

## Outputs

- 📈 growth_diagnosis.md
- 🎯 quarterly_okrs.md
- 📅 quarter_timeline.md
