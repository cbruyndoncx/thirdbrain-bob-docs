## Inputs

- 📋 Project or engagement name
- 📅 Time period to review
- 💬 Key pain points or highlights

## What BOB does

1. task-wrapup → guided retrospective interview
2. Review findings — confirm accuracy, add context
3. ai-work-audit → pull session metrics and deliverables
4. task-wrapup → propose skill improvements and templates
5. Approve and apply proposed changes

## Outputs

- 📝 Retrospective summary
- 📊 Session metrics and productivity analysis
- ⚙️ Applied skill improvements
- 📐 Reusable templates extracted

## Benefits

- 4× faster
- Structured capture — not vague 'what went well'
- Templates extracted for next time
