## Inputs

- 📦 What to produce (product, variant, batch size)
- 📅 When it's needed (delivery deadline working backwards)
- 📋 Current raw material stock levels
- 📦 Production capacity constraints
- 📋 Quality standards to meet

## What BOB does

1. production-planning → forecast demand from order pipeline and historical patterns
2. production-planning → create production schedule, allocate work centers, set milestones
3. Review and approve production plan — adjust priorities and quantities
4. purchase-requisition → identify material gaps, create purchase requests for raw materials
5. Execute production run — manufacture according to schedule
6. Quality inspection — test against standards, document results, quarantine defects
7. inventory-management → receive finished goods into inventory, update stock levels
