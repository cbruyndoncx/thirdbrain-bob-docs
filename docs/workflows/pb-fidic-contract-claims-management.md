# FIDIC Contract Claims Management

*FIDIC Claims Lifecycle*

> New FIDIC project.
> Claims readiness starts now, not when things go wrong.

| | |
|---|---|
| **Area** | Project Delivery |
| **Time savings** | Weeks of manual work → hours with agent assistance |
| **Try it** | "New FIDIC project awarded — set up claims readiness" |
| **Compounding** | Each claim strengthens the precedent library across projects |
| **Frequency** | Per project · per delay event |

## Inputs

- 📜 contract-docs.pdf
- 📊 baseline-schedule.xlsx
- 📁 site-records

## What BOB does

1. project-context → establish baseline
2. contract-clause-analyzer → risk register
3. Review high-risk clauses
4. variation-order-analyzer → assess VOs
5. delay-analysis-tool → run TIA
6. eot-claims-preparer → draft notice
7. Review and submit claim

## Outputs

- ⚠️ risk_register.md
- 📋 variation_register.md
- 📕 eot_claim.md
