# Kaizen My Process

*Prioritized, stakeholder-vetted improvement backlog with a visual process map, PDCA + 5S artifacts, an improved SOP, and a re-baseline cadence*

> Owner or client wants to systematically improve a specific documented process (continuous improvement / Kaizen)

**Outcome:** Prioritized, stakeholder-vetted improvement backlog with a visual process map, PDCA + 5S artifacts, an improved SOP, and a re-baseline cadence

| | |
|---|---|
| **Area** | Operations |
| **Time savings** | Typical run: 2-4 hours, multi-session |
| **Try it** | Owner or client wants to systematically improve a specific documented process (continuous improvement / Kaizen) |
| **Frequency** | 2-4 hours, multi-session |

## Inputs

- 📋 Process name and a description or link to its current documentation
- 📋 Improvement goal (single, concrete)
- 📋 Process owner + key participants
- 📋 Any known pain points / recent failures
- 📋 Cadence for the re-baseline (e.g. quarterly)

## What BOB does

1. business-baseline → map the target process as a swimlane; flag bottlenecks and candidate waste
2. Confirm the map and set the explicit improvement goal; correct any inaccuracies
3. process-kaizen (waste-audit) → classify the flags into the 8 Lean wastes, estimate annual cost, write audit-waste findings + a gemba-walk guide
4. ask-boardroom → convene a 5-expert panel (role · interests · concerns) to critique the process from diverse lenses; one stakeholder per pass
5. prioritization-craft → vet the full idea list (panel critique + waste findings) down to the top 5–10 improvements ranked against the goal
6. Select which improvements to implement now vs. backlog
7. process-kaizen (improvement-kit) → produce the 5S checklist, PDCA (Plan-Do-Check-Act) cycle, and standard-work doc for the process
8. playbook-runner → capture the improved process as an SOP / recurring playbook so the gain is standardized
9. scheduled-jobs → schedule a re-baseline TaskNote to re-run step 1 next cycle and measure the delta
