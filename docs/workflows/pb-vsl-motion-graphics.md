## Inputs

- 🎯 Product/offer being sold
- 🎨 Visual style and brand assets
- ⏱️ Target video length (60-90s)

## What BOB does

1. Define VSL objective, target audience, and CTA
2. explainer-video-guide → write script with scene plan
3. copy-editing → clarity and persuasion sweep
4. Review script and scene plan
5. remotion-reference-pack → build Remotion composition
6. marketing-video-guide → generate voiceover
7. Remotion render → render with voiceover and captions
8. Review rendered video, flag issues
9. Apply revisions and re-render
10. content-scorer → score persuasion and CTA strength

## Outputs

- 📝 PAS/BAB script with scene plan
- 💻 Remotion composition source
- 🎥 Rendered motion graphics VSL
- 📊 Content score report
