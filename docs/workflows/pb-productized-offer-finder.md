## Inputs

- 🏢 Business: what they sell, to whom, who pays them
- 🎯 ICP: top 2-3 pains and recurring triggers
- 📋 Current offers (paid + free); identify gaps in the value ladder
- 📋 Existing offer ideas (or "start fresh")
- 📋 Build capacity: solo founder, small team, has dev resources
- 📅 Constraints: brand voice, regulatory, time-to-launch deadline

## What BOB does

1. vault-preflight → verify business/client context completeness; flag missing ICP, profile, or marketing context before starting
2. icp-discovery OR business-baseline → if ICP/profile missing, run discovery; if both present, skip to step 3
3. ai-usecase-discovery → ideate AI use cases for the buyer's domain; produces a long candidate list
4. free-tool-strategy / productized-offer route → shape candidates into 3-5 ranked productized offers across the four format categories (audit, playbook, roadmap, mini-system); each tagged with value-ladder slot, RICE, AI-fit, stack, ROI
5. Review shortlist; pick top idea OR adjust ranking based on founder constraints (build capacity, brand fit, urgency)
6. prioritization-craft → optional deeper RICE/ICE comparison if shortlist is contested or close-scored
7. pricing-strategy → confirm value-ladder slot for the chosen idea; recommend price point and tier structure
8. zero-to-launch → MVP brief for the chosen idea (week-1 scope, build approach, success criteria)
9. product-testing → validation plan: smoke test, landing-page test, or pre-sale before development begins

## Outputs

- 📋 Offer Shortlist.md
- 🗺️ Value-Ladder Map.md
- 📋 MVP Brief.md
- 💰 Pricing Tiers.md
- 🗺️ Validation Plan.md
