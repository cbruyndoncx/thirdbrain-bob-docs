## Inputs

- 📊 Current metrics: MRR/ARR, monthly churn %, NPS score, organic acquisition %
- 📦 Sean Ellis test result if available ("How would you feel if you could no longer use this product?" — % answering "very disappointed")
- 🎙️ Top 3 reasons customers buy (from sales calls or surveys)
- 📋 Top 3 reasons customers churn or don't buy
- 👤 Competitor names customers mention

## What BOB does

1. Gather PMF metrics — collect retention rate, churn, MRR/ARR, NPS, organic acquisition %, referral rate, switching cost signals
2. ask-boardroom → configure 5 PMF-adversarial advisors and run the debate
3. Review board output — read position papers, rebuttals, and vote tally
4. Score PMF dimensions from board debate into a structured scorecard
5. Review scorecard and identify top 3 PMF gaps to address
6. decision-frameworks → create action plan for closing the top PMF gap

## Outputs

- 🎙️ Boardroom Transcript.md
- 📊 PMF Scorecard.md
- 📋 Top 3 Gap List.md
- 🗺️ Action Plan.md
