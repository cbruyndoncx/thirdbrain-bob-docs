## Inputs

- 🏢 Customer name and client_id
- 📋 Issue description (what happened, when, impact)
- 📋 Severity assessment (critical / major / minor)
- 📋 Any prior communication about the issue
- 📦 Desired outcome from customer's perspective

## What BOB does

1. escalation-routing → assess severity, classify issue, determine routing and urgency
2. Acknowledge issue to customer within SLA window — confirm receipt and expected timeline
3. Implement fix or workaround — resolve the immediate problem
4. Confirm resolution with customer — verify satisfaction, document what was done
5. client-health-tracker → update health score, flag if at-risk, log recovery action

## Outputs

- 📋 Severity Decision.md
- 📄 RCA Document.md
- 📋 Resolution Record.md
- 📊 Health Score.md
- 📋 Lessons Log.md
