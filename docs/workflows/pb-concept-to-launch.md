## Inputs

- 🎯 Idea description (problem, proposed solution, target user)
- 📋 Competitive landscape awareness
- 💰 Available resources (budget, team, timeline)
- 📋 Success criteria (what does "working" look like?)

## What BOB does

1. jtbd-building → map customer jobs, push/pull forces, and current workarounds
2. market-sizing-analysis → calculate TAM/SAM/SOM for the opportunity
3. Decide: pursue, pivot, or park the idea based on market size and JTBD fit
4. zero-to-launch → scope week-1 MVP, prioritize requirements, map user flows
5. design-first-dev → define UX requirements, all-state design, and craft standards
6. exp-driven-dev → design A/B test, set primary and guardrail metrics, run experiment
7. positioning-craft → craft positioning, differentiation, and value proposition
8. launch-execution + launch-strategy → write launch copy, plan go-to-market, execute launch
9. metrics-frameworks → define north star metric, set review cadence, measure initial results

## Outputs

- 🗺️ JTBD Map.md
- 📋 TAM-SAM-SOM.md
- 📦 MVP Spec.md
- 📋 Positioning.md
- 📅 Launch Plan.md
- 📊 North Star Metric
