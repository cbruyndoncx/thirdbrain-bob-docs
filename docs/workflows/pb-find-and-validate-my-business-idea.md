## Inputs

- 🎯 Current situation + near-term money goal (replace salary / $10K/mo / $30K/mo / fundable)
- 📋 The four Ikigai lists (love / good at / world needs / pays) — drawn out in step 2
- 📅 Build capacity and any constraints (brand, regulatory, time-to-launch)
- 🎯 Existing offers/ICP if any (or "start fresh")

## What BOB does

1. vault-preflight → check for existing business/ICP context so downstream steps sharpen rather than rebuild; flag what's present
2. idea-validator → Ikigai four-list discovery → niche sharpening → live market-research sweep → 100-point validation score with kill-criteria; emits a validated-idea handoff note
3. positioning-craft → competitive map + differentiation + the unfair-advantage statement, anchored to the validated niche and the research findings
4. offer-builder → value-stack offer (dream outcome, obstacles, deliverables, one high-value bonus) built from the validated niche and buyer language
5. pricing-strategy → market-anchored three-tier pricing + income math against the founder's step-2 money goal; pressure-test that the math pencils
6. guarantee-designer → risk-reversal guarantee tied to the buyer's #1 fear
7. Assemble the deliverables: a one-page brief (`pdf-report` or `branded-pdf`), the branded HTML report, and a 7-day action plan; route per the validated-idea note's location

## Outputs

- 📊 Validated Idea + Score.md (the idea-validator handoff note — the gate artifact)
- 🗺️ Competitive Map + Unfair Advantage.md
- 📋 Offer Stack.md
- 💰 Pricing Tiers + Income Math.md
- 📋 Guarantee.md
- 📊 Idea Brief.md + Idea Report.html + 7-Day Plan
