## Inputs

- 📋 marketing_context.md
- 🎯 ICP / target audience
- 🔗 competitor URLs (optional)

2. Identifying content pillars (4 lenses)
3. Mapping keywords to buyer journey stages
4. Running competitor content gap analysis
5. Scoring and prioritizing topic ideas
6. Building topic cluster map

## Outputs

- 📊 Priority Topics Table
- 🗺️ Topic Cluster Map
