# Trend To Content Pipeline

*Community signals become dated, evidenced content briefs that a writer can act on without re-reading the source threads*

> The good ideas are in threads you already read and forgot.

- **Area:** Marketing
- **Time savings:** Typical run: 60–90 min per cycle (step 2 dominates; faster once the query set stabilises)
- **Try it:** "The content calendar is being filled from what we feel like writing rather than from what the audience is actively arguing about — or a recurring source of grounded content ideas is needed"
- **Compounding:** Each run refines templates and context — 0 automated steps improve with accumulated data
- **Frequency:** Per trigger event

## Inputs

- 📋 Source and query set (from step 1, reused across cycles)
- 🎯 ICP
- 📅 Cycle date and the previous cycle's source record

## Outputs

- ✏️ Dated content briefs, each with debate, verbatim language, sources, angle, and rationale
- 📋 A cycle record: sources swept, clusters found, clusters dropped and why
