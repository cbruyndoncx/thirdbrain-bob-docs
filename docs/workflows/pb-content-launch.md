## Inputs

- 🏢 Client profile
- 📋 marketing_context.md
- 🎯 Campaign objectives

## What BOB does

1. content-destinations → Map goals, signals, passengers
2. Review destinations map
3. icp-discovery → Validate passengers
4. content-strategy → SEO keyword validation
5. Approve topics and priorities
6. copywriting → Write content pieces
7. content-scorer → Quality check
8. Review and approve content
9. social-content → Platform-specific posts
10. content-repurposer → Additional formats
11. Review social and repurposed content
12. ab-test-setup → Design experiments
13. analytics-tracking → GA4 conversion events
14. metrics-frameworks → North star metric
15. content-destinations → Monthly review

## Outputs

- 🗺️ Content Destinations Map
- 📝 Scored Blog Posts
- 📱 Social Content Pack
- 🧪 A/B Test Plans
- 📊 GA4 Tracking Config
- 📈 Metrics Dashboard

## Benefits

- Saves 40+ hours vs manual
- Strategy and execution in one flow
- Measurement built in from the start
