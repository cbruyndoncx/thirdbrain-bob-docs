> The contract is signed.

| | |
|---|---|
| **Area** | Operations |

## Inputs

- 📜 contract-clauses.pdf
- 📋 particular-conditions.pdf

## What BOB does

1. Identify edition and book color
2. Clause-by-clause risk analysis
3. Flag deviation from standard
4. Map obligations and deadlines
5. Review risk register
6. Compile analysis report
