# Competitor Teardown

*One competitor is documented from primary sources, with a defensible position on where they beat us, where we beat them, and what would have to change for that to flip*

> Everyone has an opinion about the competition. Nobody has the file.

| | |
|---|---|
| **Area** | Marketing |
| **Time savings** | Typical run: 2–4 h (step 2 dominates; longer if the competitor's pricing is gated) |
| **Try it** | "A competitor keeps appearing in lost deals, has shipped something that changes the comparison, or is about to be named in positioning or sales copy that has no evidence behind it" |
| **Compounding** | Each run refines templates and context — 0 automated steps improve with accumulated data |
| **Frequency** | Per opportunity |

## Inputs

- 👤 Competitor name and trigger
- 📋 Overlapping offers
- 🎯 Intended output and audience
- 🏢 Access to closed-deal notes under `30-CLIENTS/{id}/01-DEALS/`

## Outputs

- 📅 A dated teardown note holding the evidence and the honest comparison
- 📋 Optionally a battlecard, a public comparison page, or both — each stating its own evidence bar
