# Monthly Business Review

*Close Month, Set Priorities*

> Another month gone.
> No review, no trend, same priorities as last month.

| | |
|---|---|
| **Area** | Finance |
| **Time savings** | ~6 hrs manual → ~60 min automated |
| **Try it** | "Run monthly review" or first week of month |
| **Compounding** | Trend detection sharpens — each review builds on prior months |
| **Frequency** | Monthly |

## Inputs

- 📋 last-month-priorities.md
- 💰 financial-data

## What BOB does

1. financial-reporting → P&L and cash
2. business-reporting → month-over-month
3. Flag anomalies
4. crm-pipeline → pipeline health
5. project-status → delivery status
6. Identify binding constraint
7. prioritization-craft → RICE priorities

## Outputs

- 📊 monthly_review.md
- 📈 pipeline_health.md
- 🎯 priorities_next_month.md
