- **Area:** Sales & Clients

- **Compounding:** Each onboarding builds reusable templates and baseline data
- **Frequency:** Per new client
- **Published:** 2026-07-01

## Inputs

- 🏢 Client name + industry
- 🔗 Website URL
- 👤 Key contacts
- 📋 Engagement scope
- 🌍 Operating region(s)

## What BOB does

1. regional-context → confirm the client's region KB is fresh
2. create-client → set up workspace folders + profile, capture regions
3. Review client profile, add details, confirm regions
4. business-baseline → business map with Three-Layer Context (World→Country→Industry)
5. Review business map, flag corrections
6. vault-preflight → verify context + region KB freshness
7. Deliver 'Your Operating Environment Right Now' briefing

## Outputs

- 📁 Workspace folders
- 🪪 Client profile (+regions)
- 🗺️ Business map (3-layer)
- ✅ Context completeness report
- 📑 Operating Environment briefing

## Benefits

- 4× faster
- Nothing gets missed
- Baseline context from day one
