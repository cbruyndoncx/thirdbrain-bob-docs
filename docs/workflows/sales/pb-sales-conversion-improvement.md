## Inputs

- 🏢 Client name and industry
- 📉 Current conversion rate and top objections
- 🏷️ Competitor names and average deal size

## What BOB does

1. icp-discovery → validate buyer persona and triggers
2. positioning-craft → define differentiated value prop
3. brand-voice-generator → align sales voice with brand
4. Review positioning and voice — confirm direction
5. copywriting → rewrite key sales pages and CTAs
6. proposal-writer → create proposal template
7. consultative-selling → build discovery questions + objection playbook

## Outputs

- 🎯 Differentiated positioning statement
- 📝 Rewritten sales pages and CTAs
- 📄 Proposal template
- 🛡️ Objection handling playbook
