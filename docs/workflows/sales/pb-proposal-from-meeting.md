- 👤 Client name
- 💰 Budget range (if discussed)

1. meeting-intelligence → extract decisions, needs, action items
2. Review extracted needs, confirm scope
3. proposal-writer → draft proposal from findings
4. Review and adjust proposal
5. docx-tools → generate branded .docx
