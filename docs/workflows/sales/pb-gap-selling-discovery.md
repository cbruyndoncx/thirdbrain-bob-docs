# Gap Selling Discovery

*Current State and Future State mapped, gap quantified in dollars and performance metrics, urgency created, solution positioned as the bridge*

> The prospect is fine as they are.
> Until someone puts a number on the gap.

- **Area:** Sales & Clients
- **Time savings:** Typical run: 2-4 hours across pre-call prep, discovery call, and gap analysis documentation
- **Try it:** "Prospect is comfortable with status quo, no urgency to change — need to surface and quantify the gap between current and future state"
- **Compounding:** Each run refines templates and context — 5 automated steps improve with accumulated data
- **Frequency:** Per opportunity
- **Published:** 2026-08-01

## Inputs

- 🏢 Prospect company name and URL
- 👤 Contact name and role
- 🏭 Industry benchmarks (average performance, peer comparison data)
- 📋 Known pain points or triggers (if any prior discovery)
- 💰 Your service offering and pricing range

## What BOB does

1. research-company → gather company intelligence, current performance indicators, technology stack, competitive position
2. consultative-selling → generate Gap Selling discovery question bank: Current State mapping questions, Future State vision questions, gap quantification prompts
3. Review question bank, prepare industry benchmarks and gap data for the call
4. Conduct discovery call: map Current State (processes, tools, performance, costs) → define Future State (ideal outcomes, capabilities, metrics) → quantify the gap together
5. meeting-intelligence → extract Current State facts, Future State vision, gap dimensions, and urgency signals from call notes
6. consultative-selling → build gap analysis document: quantify financial gap, performance gap, time gap, capability gap; model cost of inaction over 3-6-12 months
7. Review gap analysis, validate numbers, prepare urgency framing and solution positioning
8. consultative-selling → generate diagnostic brief positioning your solution as the bridge from Current to Future State, with ROI calculation and proof points

## Outputs

- 📋 Question Bank.md
- 🗺️ State Map.md
- 📊 Gap Analysis.md
- 💰 Cost-of-Inaction Model.md
- 📋 Diagnostic Brief.md
