# Mutual Action Plan

*Internal close plan built, buyer-facing mutual action plan prepared when appropriate, and deal path to signature made explicit*

> Everyone says the deal is closing.
> Nobody can say by when, or how.

- **Area:** Sales & Clients
- **Time savings:** Typical run: 45-90 minutes to establish; 10-20 minutes to update after each material deal event
- **Try it:** "Active deal needs an explicit path to signature with milestones, owners, and decision checkpoints"
- **Compounding:** Each run refines templates and context — 6 automated steps improve with accumulated data
- **Frequency:** Per opportunity

## What BOB does

1. vault-preflight → confirm the deal record, stage, and latest notes exist before planning against stale information
2. crm-pipeline → read current stage, next action, due dates, and pipeline activity to establish the live deal state
3. MEDDPICC Qualification → extract decision process, paper process, economic buyer access, and known procurement dependencies
4. meeting-intelligence → extract latest commitments, open questions, and whether a concrete next step was actually secured
5. Review the plan and separate what stays internal from what can be shared with the buyer
6. negotiation → prepare responses for milestones that carry commercial, legal, or procurement friction
7. crm-pipeline → sync the single most important next action and due date back to the deal record so weekly pipeline review stays accurate

## Outputs

- 🗺️ Internal Close Plan.md
- 🗺️ Mutual Action Plan.md
- 📅 Updated deal note in [[crm-pipeline]]
