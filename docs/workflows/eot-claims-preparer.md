# Eot Claims Preparer

*FIDIC Extension of Time Claims*

> You have 28 days to notify.
> Miss it and the claim is dead.

| | |
|---|---|
| **Area** | Operations |
| **Level** | expert |
| **Roles** | Operations Manager |
| **Time savings** | ~3-5 days manual drafting → ~45 min automated |
| **Try it** | "Draft a 28-day notice for a delay caused by late Employer drawings" |
| **Compounding** | Each claim builds precedent library — rebuttal patterns and evidence templates improve |
| **Frequency** | Per delay event · per claim cycle |

## Inputs

- 📝 delay-event.md
- 📊 tia_report.md
- 📁 site-records

## What BOB does

1. Establish entitlement basis
2. Check 28-day notice window
3. Draft notice letter
4. Review and sign notice
5. Prepare detailed claim
6. Anticipate rebuttals

## Outputs

- 📨 eot_notice.md
- 📕 eot_claim.md
- ✅ compliance_check.md
