# Solo Weekly Operating System

*Weekly Cadence for Solo Operators*

> No team. No manager.
> Just you, and whatever you remember to do.

| | |
|---|---|
| **Area** | Strategy |
| **Time savings** | ~3 hrs Monday admin → ~30 min automated |
| **Try it** | "Run my weekly system" or every Monday |
| **Compounding** | Pipeline discipline compounds — nothing falls through the cracks |
| **Frequency** | Weekly |

## Inputs

- 📬 inbox
- 📊 pipeline-data
- 📅 calendar

## What BOB does

1. email-triage → classify inbox
2. crm-pipeline → deals and follow-ups
3. booking-scheduler → meeting prep
4. Set weekly focus (max 3)
5. social-content → draft visibility post

## Outputs

- 📬 triaged_inbox.md
- 🎯 weekly_focus.md
- 📝 linkedin_post.md
