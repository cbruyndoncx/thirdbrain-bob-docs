# BOB Docs

Public documentation for BOB: the vault wiki, plus the skills and workflows library.
Built with MkDocs Material and deployed to GitHub Pages (`.github/workflows/pages.yml`).

The vault is the source: edit the wiki in Obsidian, then sync. Obsidian does not follow
symlinks out of the vault, so the published part is copied into this repository.

| Folder | What | Edit by hand? |
|---|---|---|
| `wiki/` | Raw Obsidian wiki: only the pages and images the export publishes | No, `sync_wiki.sh` overwrites it |
| `data/catalogue.json` | The skills and workflows library as data, limited to the latest full release; written by the website's `scripts/emit_catalogue.py` | No, `sync_catalogue.sh` overwrites it |
| `docs/` | Generated by `scripts/build.sh`, in CI and locally; not committed | No |
| `reports/wiki-export.md` | Unresolved links, dropped blocks, draft pages, missing images | No |

## Publish a docs change

    scripts/sync_wiki.sh              # copy, build --strict, commit, push; CI deploys in about 2 minutes
    scripts/sync_wiki.sh --no-push    # same, without the pull and push

Optional argument: `[VAULT_WIKI]` after the flag.

## Publish the library after a release

    scripts/sync_catalogue.sh         # emit catalogue.json for the latest thirdbrain-full tag, build, commit, push

Optional arguments: `[VAULT] [WEBSITE_REPO]` after `--no-push`. The emitter reads the
release-history repository (found through the vault's release-ops settings) and leaves out skills
and playbooks added to the vault after the release. The website applies the same filter.

## Build locally

    scripts/build.sh && mkdocs serve

- `scripts/export_wiki.py` converts the wiki (wikilinks, embeds, callouts) and drops internal folders; see `EXCLUDE_PATHS`. Pages with `publish: false` are skipped.
- `scripts/build_library.py` builds `docs/skills` and `docs/workflows` from `data/catalogue.json`.
