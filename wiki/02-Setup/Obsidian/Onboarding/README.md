## How This Vault Works

```
You speak naturally to Claude Code
        ↓
Claude activates the right skill
        ↓
Skill guides Claude through the workflow
        ↓
Output returned in the chat; some workflows also save files to your vault
```

**You don't need to know which skill to use.** Just describe what you want. Claude figures out the rest.
