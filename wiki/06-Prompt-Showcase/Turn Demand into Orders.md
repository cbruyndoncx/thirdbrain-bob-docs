# Turn Demand into Orders

← [[Prompt Showcase]] · value chain: **market-to-order**

> **Turn demand into orders — signals through pricing, campaigns, qualified orders.**

## How this works

This area moves work through these stages:

**signal → analyze → price → campaign → qualify → order**

You don't run the stages by hand. You **just ask** — in plain language — and the system routes you to the right tool. There are two kinds:

- **Skills** — a single capability ("write me social posts", "score this lead").
- **Playbooks** — a guided, multi-step workflow that chains skills into a whole outcome.

Reach for a **skill** for one task; reach for a **playbook** for a whole outcome.

## How to trigger — just say it

No commands to memorize. Speak in plain language and the system picks the tool:

- *"Help me set pricing — I'm not sure what to charge."* → pricing-strategy
- *"What are the signals telling me about demand?"* → demand-signal-analysis
- *"Set up an A/B test so I learn what works."* → ab-test-setup
- *"Convert this market demand into orders."* → the **Market-to-Order** playbook

> [!tip] Skill or playbook?
> 🟢 Start with single asks (one skill). 🔵 When you want a whole outcome, run a **playbook** — it sequences many skills for you.
